# Mavo Gugu Gubayi — Portfolio

A responsive personal portfolio website for Mavo Gugu Gubayi, built with React, TypeScript, Vite, and Tailwind CSS.

## Included

- Responsive one-page layout with sticky navigation and mobile menu
- About, skills, projects, education, certifications, experience, and contact sections
- Accessible semantic structure, visible focus states, descriptive image text, and reduced-motion support
- Downloadable starter CV at `public/Mavo-Gugu-Gubayi-CV.html`
- SEO page title, description, Open Graph metadata, and theme color

## Customising the placeholders

Update the content in `src/App.tsx` for verified biography, skills, projects, education, certifications, experience, GitHub, and LinkedIn details. Replace `public/Mavo-Gugu-Gubayi-CV.html` with a final CV when ready. The current contact form provides visual confirmation only; connect it to a form service or backend before publishing if you want visitors to submit messages directly.

## Build and deployment

The project is ready for static hosting on GitHub Pages, Vercel, Netlify, or a similar provider. Use the standard production build output from Vite and configure the host to serve `index.html` for the root page.
